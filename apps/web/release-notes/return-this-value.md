A function returns a step's value when you turn on Return this value in the step's Execution section. The key it comes back under is shown beside the switch, and you can set your own under Response key. Naming a step EXPORT_… still works, but you no longer need to. Under the code editor, the panel now lists the earlier steps the body can read by name.
