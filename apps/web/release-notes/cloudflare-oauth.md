link: connections
linkLabel: Connect an account

Connections can now authorize a Cloudflare account in the browser instead of pasting an API token — for the organization, a project, or a workspace. The connection renews itself, shows when a deploy permission is missing, and can be reconnected in place. Cloudflare connections now request Workers Admin, which is what Cloudflare requires to create the Worker on a first deploy. Reconnect a connection made before this update.
