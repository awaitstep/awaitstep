Nodes on the canvas take connections in on the top and left and send them out on the bottom and right, so a branch can sit beside the main path. Hover a node for a + on each free side; click it to pick the next node, and it lands there already joined. Links now point the way a run goes, and the ones around the node you hover or select show it moving.
