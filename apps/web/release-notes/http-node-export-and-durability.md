An HTTP request is no longer put in a function's response automatically, and a sub-workflow or a sub-script can be taken out. Every node with a value now has the same Return this value switch. HTTP requests no longer run as a step by default — turn Durable on for retries and a timeout — and their Headers, Query and Body fields are now tabs.
