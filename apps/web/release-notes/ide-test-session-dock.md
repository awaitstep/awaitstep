Press Option+Enter (Alt+Enter on Windows and Linux) to run what you are editing: a step is tried in your browser, anything else goes through a test session. Output and Run are now one Test session tab with timestamps, a filter and Follow, and your trigger payload is remembered. Run asks before using a session that doesn’t have your unsaved files, and you can cancel a session while it starts.
