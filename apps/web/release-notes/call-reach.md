title: Calls stay inside a workspace, unless shared
link: projects
linkLabel: Open your projects
---

A workflow or function can now only call what is in its own workspace, or what another workspace of the same project has shared. Saving a call to anything else warns you and names the node; a deploy, a test session or a local run refuses it.
