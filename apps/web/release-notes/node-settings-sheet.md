The step panel on the canvas now shows the file the code lives in, lets you enlarge the editor to fill the panel, and folds retries, delay, backoff and timeout under one Execution line that says what is set. An edit made just before you close or switch panels is kept, and leaving an empty Retry delay no longer turns retries on. A step saved earlier with an empty Retry delay counts as having no retry settings from its next deploy, so it may be grouped with the plain steps next to it. On a read-only version the panel shows the node without accepting edits.
