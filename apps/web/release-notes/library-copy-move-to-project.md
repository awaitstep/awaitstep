title: Copy or move scripts and nodes to the project
link: projects
linkLabel: See your projects
---

A workspace's module or custom node can now be copied or moved to the project from its row menu on Scripts & nodes, so every workspace in the project can use it. A move keeps its versions, and the workflows using it keep working.
