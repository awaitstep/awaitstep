title: One API key for several projects or workspaces
link: api-keys
linkLabel: Manage API keys
---

An API key can now reach a set of projects or workspaces at once — one key, one secret. Each project or workspace can revoke its own access without affecting the others, and the owner can still revoke the whole key in one step.
