title: Watch a test run's instance as it runs
link: projects
linkLabel: Open a workflow

A workflow's test session now has an Instance pane beside Output. It shows the run's status and its steps as they happen, with each retry's error and each step's output. From it you can send an event to a run that is waiting or end the run. Steps show on Cloud test runs.
